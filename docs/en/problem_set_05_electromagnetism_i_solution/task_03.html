Problem 3 – Electric Field from Two Positive Charges

We study the electric field created by two point charges: \(+q\) at \((-a,0)\) and \(+2q\) at \((a,0)\).

1. General Electric Field \(\vec E(x,y)\)

We use Coulomb’s law. For a point charge, the electric field is

\[ \vec E=kQ\frac{\vec r-\vec r_Q}{|\vec r-\vec r_Q|^3} \]

The point where we calculate the field is

\[ P=(x,y) \]

Field from \(+q\) at \((-a,0)\)

The vector from the charge to the point \(P\) is

\[ \vec r_1=(x,y)-(-a,0)=(x+a,y) \]

Therefore,

\[ \vec E_1= kq\frac{(x+a,y)} {\left[(x+a)^2+y^2\right]^{3/2}} \]

Field from \(+2q\) at \((a,0)\)

The vector from the charge to the point \(P\) is

\[ \vec r_2=(x,y)-(a,0)=(x-a,y) \]

Therefore,

\[ \vec E_2= 2kq\frac{(x-a,y)} {\left[(x-a)^2+y^2\right]^{3/2}} \]

The total field is the vector sum:

\[ \boxed{ \vec E(x,y)= kq \left[ \frac{(x+a,y)} {\left[(x+a)^2+y^2\right]^{3/2}} + 2\frac{(x-a,y)} {\left[(x-a)^2+y^2\right]^{3/2}} \right] } \]

2. Field on the \(y\)-axis: \(\vec E(0,y)\)

On the \(y\)-axis,

\[ x=0 \]

Substitute \(x=0\) into the general formula:

\[ \vec E(0,y)= kq\frac{(a,y)}{(a^2+y^2)^{3/2}} + 2kq\frac{(-a,y)}{(a^2+y^2)^{3/2}} \]

Factor out the common denominator:

\[ \vec E(0,y)= \frac{kq}{(a^2+y^2)^{3/2}} \left[(a,y)+2(-a,y)\right] \]

Simplify:

\[ (a,y)+2(-a,y)=(-a,3y) \]
\[ \boxed{ \vec E(0,y)= \frac{kq}{(a^2+y^2)^{3/2}}(-a,3y) } \]

So the components are:

\[ \boxed{ E_x(0,y)= -\frac{kqa}{(a^2+y^2)^{3/2}} } \]
\[ \boxed{ E_y(0,y)= \frac{3kqy}{(a^2+y^2)^{3/2}} } \]

3. Field on the \(x\)-axis: \(\vec E(x,0)\)

On the \(x\)-axis,

\[ y=0 \]

Substitute \(y=0\):

\[ \boxed{ \vec E(x,0)= kq \left[ \frac{x+a}{|x+a|^3} + 2\frac{x-a}{|x-a|^3} \right]\hat i } \]

There is no \(y\)-component on the \(x\)-axis:

\[ \boxed{ E_y(x,0)=0 } \]

4. Conditions for \(E_x=0\), \(E_y=0\), and \(\vec E=0\)

Condition for \(E_x=0\)

\[ \boxed{ \frac{x+a} {\left[(x+a)^2+y^2\right]^{3/2}} + 2\frac{x-a} {\left[(x-a)^2+y^2\right]^{3/2}} =0 } \]

Condition for \(E_y=0\)

The \(y\)-component is

\[ E_y= kqy \left[ \frac{1} {\left[(x+a)^2+y^2\right]^{3/2}} + \frac{2} {\left[(x-a)^2+y^2\right]^{3/2}} \right] \]

The bracket is always positive, so the only way to get \(E_y=0\) is

\[ \boxed{y=0} \]

Condition for \(\vec E=0\)

For the whole field to be zero, we need both:

\[ E_x=0 \qquad \text{and} \qquad E_y=0 \]

Since \(E_y=0\) requires \(y=0\), the zero field can only be on the \(x\)-axis.

Between the charges, \(-a

\[ \frac{1}{(x+a)^2} = \frac{2}{(a-x)^2} \]

Solving gives:

\[ \boxed{ x_0= a\frac{1-\sqrt2}{1+\sqrt2} } \]

Therefore, the zero-field point is

\[ \boxed{ (x,y)= \left( a\frac{1-\sqrt2}{1+\sqrt2}, 0 \right) } \]

5. Numerical Example

Given:

\[ a=0.2\,\mathrm{m}, \qquad y=0.3\,\mathrm{m}, \qquad q=2\,\mu\mathrm{C} \]

On the \(y\)-axis:

\[ \vec E(0,y)= \frac{kq}{(a^2+y^2)^{3/2}}(-a,3y) \]

Substitute:

\[ (a^2+y^2)^{3/2} = (0.2^2+0.3^2)^{3/2} = (0.13)^{3/2} \approx 0.04687 \]
\[ \frac{kq}{(a^2+y^2)^{3/2}} = \frac{(8.99\times10^9)(2\times10^{-6})}{0.04687} \approx 3.835\times10^5 \]
\[ (-a,3y)=(-0.2,0.9) \]
\[ \boxed{ \vec E(0,0.3) \approx (-7.67\times10^4,\ 3.45\times10^5) \ \mathrm{N/C} } \]
\[ \boxed{ |\vec E| \approx 3.54\times10^5\ \mathrm{N/C} } \]

6. Limit \(y\gg a\)

When \(y\) is much larger than \(a\), we can write

\[ a^2+y^2\approx y^2 \]

Therefore,

\[ (a^2+y^2)^{3/2}\approx y^3 \]

Starting from

\[ \vec E(0,y)= \frac{kq}{(a^2+y^2)^{3/2}}(-a,3y) \]

we get

\[ \boxed{ \vec E(0,y) \approx \left( -\frac{kqa}{y^3}, \frac{3kq}{y^2} \right) } \]

The dominant term is

\[ \boxed{ \vec E(0,y) \approx \frac{3kq}{y^2}\hat j } \]

This makes sense because far away the two charges look like one total charge:

\[ q+2q=3q \]

7. Is there a zero-field point on the \(y\)-axis?

On the \(y\)-axis:

\[ \vec E(0,y)= \frac{kq}{(a^2+y^2)^{3/2}}(-a,3y) \]

The \(x\)-component is

\[ E_x(0,y)= -\frac{kqa}{(a^2+y^2)^{3/2}} \]

This is never zero if \(a\neq0\) and \(q\neq0\).

Therefore, no point of zero field exists on the \(y\)-axis.
\[ \boxed{ \text{No zero-field point exists on the } y\text{-axis.} } \]

General field

Field on the \(y\)-axis
\[ \boxed{ \vec E(0,y)= \frac{kq}{(a^2+y^2)^{3/2}}(-a,3y) } \]
Field on the \(x\)-axis
\[ \boxed{ \vec E(x,0)= kq \left[ \frac{x+a}{|x+a|^3} + 2\frac{x-a}{|x-a|^3} \right]\hat i } \]

\[ \boxed{ (x,y)= \left( a\frac{1-\sqrt2}{1+\sqrt2}, 0 \right) } \]
