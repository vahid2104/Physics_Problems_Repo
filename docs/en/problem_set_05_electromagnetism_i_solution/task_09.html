Step-by-step solution

Given idea

A dipole is made of two charges, +q and −q, separated by distance d.

p = qd

The vector p points from the negative charge to the positive charge.

1. Torque acting on the dipole

The electric field pulls the positive charge in the field direction and the negative charge in the opposite direction. These two forces create a rotating effect called torque.

τ⃗ = p⃗ × E⃗₀

The magnitude is:

τ = pE₀ sinθ

Since the torque tries to bring the dipole back to θ = 0, it is a restoring torque:

τ = −pE₀ sinθ

2. Potential energy

The potential energy of a dipole in an external electric field is:

U = −p⃗ · E⃗₀

Using the dot product:

U = −pE₀ cosθ

When θ = 0, the dipole is aligned with the field and energy is minimum.

Umin = −pE₀

When θ = π, the dipole is opposite to the field and energy is maximum.

Umax = +pE₀

3. Equation of angular motion

For rotational motion, Newton’s second law is:

τ = Iα

Angular acceleration is:

α = d²θ / dt²

So:

I(d²θ / dt²) = −pE₀ sinθ

Bring everything to one side:

d²θ / dt² + (pE₀ / I) sinθ = 0

4. Linearization for small displacement

For small angles, measured in radians:

sinθ ≈ θ

The equation becomes:

d²θ / dt² + (pE₀ / I)θ = 0

This is now a linear equation.

5. Harmonic oscillator interpretation

The standard simple harmonic oscillator equation is:

d²x / dt² + ω²x = 0

For angular motion:

d²θ / dt² + ω²θ = 0

Compare with:

d²θ / dt² + (pE₀ / I)θ = 0

Therefore:

ω² = pE₀ / I
ω = √(pE₀ / I)

The period is:

T = 2π√(I / pE₀)

Final answers

τ⃗ = p⃗ × E⃗₀
τ = −pE₀ sinθ
U = −pE₀ cosθ
d²θ / dt² + (pE₀ / I) sinθ = 0
d²θ / dt² + (pE₀ / I)θ = 0
ω = √(pE₀ / I)
T = 2π√(I / pE₀)

So, for small oscillations, the dipole behaves like a rotational harmonic oscillator.
