Step-by-Step Solution

1. Convert the charges to SI units

The charges are given in microcoulombs.

1 μC = 10⁻⁶ C

Therefore:

q₁ = 3 × 10⁻⁶ C
q₂ = -5 × 10⁻⁶ C

2. Find the vector from q₁ to q₂

The vector from q₁ to q₂ is:

r₁₂ = r₂ - r₁

Substitute the positions:

r₁₂ = (0.4, 0.3) - (0, 0)
r₁₂ = (0.4, 0.3) m

3. Calculate the distance between the charges

The distance is the magnitude of the vector:

r = √(0.4² + 0.3²)
r = √(0.16 + 0.09)
r = √0.25 = 0.5 m

So the distance between the charges is:

r = 0.5 m

4. Find the unit vector

The unit vector gives the direction from q₁ to q₂.

r̂₁₂ = r₁₂ / |r₁₂|
r̂₁₂ = (0.4, 0.3) / 0.5
r̂₁₂ = (0.8, 0.6)

5. Calculate the force magnitude

Coulomb's law is:

F = k |q₁q₂| / r²

where:

k = 8.99 × 10⁹ N m²/C²

Substitute the values:

F = 8.99 × 10⁹ × |(3 × 10⁻⁶)(-5 × 10⁻⁶)| / (0.5)²
F = 0.5394 N

|F₂| ≈ 0.539 N

6. Determine the force vector acting on q₂

Since q₁ is positive and q₂ is negative, the charges attract each other. Therefore, the force on q₂ points toward q₁.

The direction from q₁ to q₂ is:

r̂₁₂ = (0.8, 0.6)

But the force on q₂ points in the opposite direction:

F₂ = -F r̂₁₂
F₂ = -0.5394(0.8, 0.6)
F₂ = (-0.43152, -0.32364) N

F₂ ≈ (-0.432, -0.324) N

7. Calculate the potential energy

The electric potential energy is:

U = k q₁q₂ / r

Substitute the values:

U = 8.99 × 10⁹ × (3 × 10⁻⁶)(-5 × 10⁻⁶) / 0.5
U = -0.2697 J

U ≈ -0.270 J

The potential energy is negative because the charges have opposite signs.

8. Work required to separate the charges to 2 m

The work done by an external force is equal to the change in potential energy:

Wext = ΔU = Uf - Ui

The initial potential energy is:

Ui = -0.2697 J

The final distance is:

rf = 2 m

So:

Uf = k q₁q₂ / rf
Uf = -0.067425 J

Now calculate the work:

Wext = Uf - Ui
Wext = -0.067425 - (-0.2697)
Wext = 0.202275 J

Wext ≈ 0.202 J
