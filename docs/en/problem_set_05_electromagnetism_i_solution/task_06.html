1. Electric Field Vector Function

For a point charge, the electric field at a point (x, y) is calculated using Coulomb's law.

E⃗(x,y) = Σ k qᵢ (r⃗ - r⃗ᵢ) / |r⃗ - r⃗ᵢ|³

This means that the total field is found by adding the field from every charge.

Component form

Eₓ = Σ k qᵢ (x - xᵢ) / rᵢ³
Eᵧ = Σ k qᵢ (y - yᵢ) / rᵢ³

Here,

rᵢ = √[(x - xᵢ)² + (y - yᵢ)²]

2. Vector Field Map

The arrows in the animation show the direction of the electric field. The arrows are normalized so that we can clearly see the direction.

If the charges are positive, the electric field points away from them. If the charges are negative, the electric field points toward them.

Change the charge slider above. If q becomes negative, the arrows reverse direction.

3. Numerical Equilibrium Point

An equilibrium point is a point where the net electric field is zero.

E⃗(x,y) = 0

This means both components must be zero:

Eₓ = 0
Eᵧ = 0

In the three-charge symmetric system, the equilibrium point is at the center:

Three charges: equilibrium point ≈ (0, 0)

In the two-charge equal system, the midpoint is also an equilibrium point.

Two charges: equilibrium point ≈ (0, 0)

4. Stability Investigation

To investigate stability, we move a small positive test charge slightly away from the equilibrium point.

If the electric field pushes it back toward equilibrium, the point is stable.

If the electric field pushes it farther away, the point is unstable.

For three charges

E⃗ ≈ -C(x, y)

The negative sign means the field points back toward the center.

Three-charge case: stable in the 2D plane.

For two charges

Eₓ ≈ -C₁x
Eᵧ ≈ +C₂y

This means the field is restoring in one direction but repelling in the other direction.

Two-charge case: saddle point, so it is unstable in the 2D plane.

5. Comparison

The three-charge system and the two-charge system both have equilibrium points. However, their stability is different.

Three equal positive charges: equilibrium at center, stable in the 2D plane.
Two equal positive charges: equilibrium at midpoint, unstable saddle point.

Therefore, the main difference is that the three-charge arrangement can create a restoring field in the plane, while the two-charge arrangement cannot.
